# Баг-репорт #4: Секреты (токен бота) попадали в публичный HTML вместо плейсхолдеров

- **Severity:** Critical
- **Priority:** High (безопасность)
- **Компонент:** Сборка / деплой (GitHub Actions)
- **Окружение:** Репозиторий, статическая сборка `index.html`
- **Status:** Fixed

## Шаги воспроизведения
1. Открыть исходник `index.html` в репозитории.
2. Просмотреть блок настроек обратной связи (`BOT_TOKEN`, `ADMIN_CHAT_ID`).

## Фактический результат
В коде напрямую прописаны реальный токен Telegram-бота и `chat_id` администратора —
они попадают в публичный репозиторий и в отдаваемую страницу.

## Ожидаемый результат
В репозитории хранятся только плейсхолдеры, реальные значения подставляются на этапе деплоя
из GitHub Secrets.

## Причина и исправление
Ручная подстановка секретов заменена на плейсхолдеры `%%BOT_TOKEN%%` и `%%ADMIN_CHAT_ID%%`;
добавлен GitHub Actions workflow `deploy.yml`, который подставляет значения из `secrets`
при пуше в `main`.
