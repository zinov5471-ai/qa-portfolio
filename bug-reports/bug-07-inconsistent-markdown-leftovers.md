# Баг-репорт #7: Несогласованные символы Markdown после ручных правок — «звёздочки» появлялись снова

- **Severity:** Minor
- **Priority:** Low
- **Компонент:** Контент уроков / рендер текста
- **Окружение:** WebView мини-приложения
- **Status:** Fixed

## Шаги воспроизведения
1. Открыть уроки, отредактированные после исправления бага #6.
2. Просмотреть строки с выделениями.

## Фактический результат
В части строк оставались одиночные/непарные `**` (например `'Навыки:"Реальность"...'`,
`'**Артефакты: ...'`), из-за чего символы снова видны пользователю.

## Ожидаемый результат
Во всех строках контента отсутствуют видимые Markdown-символы.

## Причина и исправление
Правки вносились вручную и затронули не все строки — часть разметки осталась. Проведена
сплошная проверка контента и удалены оставшиеся `**`.
