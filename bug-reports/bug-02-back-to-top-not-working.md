# Баг-репорт #2: Кнопка «Наверх» не поднимает страницу с последней темы

- **Severity:** Major
- **Priority:** High
- **Компонент:** UI / кнопка «наверх» (scroll-top)
- **Окружение:** Telegram iOS, Android; WebView мини-приложения
- **Status:** Fixed

## Шаги воспроизведения
1. Открыть тему, находящуюся в конце списка на главной.
2. Прокрутить длинный урок вниз до конца.
3. Нажать кнопку «↑».

## Фактический результат
Страница не поднимается вверх, остаётся на прежней позиции прокрутки.

## Ожидаемый результат
Кнопка «↑» плавно прокручивает страницу в начало.

## Причина и исправление
Одиночного вызова прокрутки не хватало — срабатывал с задержкой относительно отрисовки.
Исправлено двойным вызовом `forceScrollTop()`.
