# Баг-репорт #1: Экран «Тема пройдена» остаётся прокрученным вниз — выглядит пустым

- **Severity:** Major
- **Priority:** High
- **Компонент:** Навигация / завершение темы
- **Окружение:** Telegram iOS, Android; WebView мини-приложения
- **Status:** Fixed

## Шаги воспроизведения
1. Открыть любую длинную тему.
2. Пройти все уроки до конца, прокручивая страницу вниз.
3. Дойти до экрана «Тема пройдена».

## Фактический результат
После завершения темы страница остаётся прокрученной вниз — пользователь видит пустой экран
и не понимает, что тема пройдена.

## Ожидаемый результат
При показе экрана «Тема пройдена» страница прокручивается вверх, экран виден сразу.

## Причина и исправление
Не выполнялся сброс прокрутки после смены экрана. Добавлен принудительный сброс прокрутки
(`forceScrollTop()`) при завершении урока.

## Подтверждение
Коммит: 93d0b31 (2026-08-29). Файл `index.html`, строка ~6964:
`forceScrollTop(); // без этого страница оставалась прокрученной вниз после "Урок пройден" — экран казался пустым`
