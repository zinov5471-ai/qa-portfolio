# Баг-репорт #5: Ошибка в подстановке токена — литерал `{BOT_TOKEN}` вместо значения

- **Severity:** Critical
- **Priority:** High
- **Компонент:** Форма обратной связи / отправка через Bot API
- **Окружение:** WebView мини-приложения (после перехода на плейсхолдеры)
- **Status:** Fixed

## Шаги воспроизведения
1. Открыть форму обратной связи.
2. Отправить сообщение.

## Фактический результат
Запрос уходит на URL `https://api.telegram.org/bot{BOT_TOKEN}/sendMessage` — фигурные скобки
не раскрываются, Bot API отвечает ошибкой, сообщение не доставляется.

## Ожидаемый результат
URL формируется с реальным токеном: `https://api.telegram.org/bot<TOKEN>/sendMessage`.

## Причина и исправление
При замене на плейсхолдер случайно использован синтаксис `{BOT_TOKEN}` вместо `${BOT_TOKEN}`
в шаблонной строке. Исправлено на корректную интерполяцию.

## Подтверждение
Коммит: e78271f (2026-07-25). Диф:
`- const url = \`https://api.telegram.org/bot{BOT_TOKEN}/sendMessage\`;`
восстановлено на корректную подстановку `${BOT_TOKEN}`.
