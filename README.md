## О проекте

Telegram Mini App (HTML/CSS/JS) с гайдами по игре Heroes of Might and Magic: Olden Era:
темы с уроками, песочница-квизы, премиум-раздел с оплатой Telegram Stars, форма обратной
связи, русский и английский языки. Приложение разработано мной с использованием ИИ-инструментов,
тестирование проводил я же — от первой версии до текущей.

## Как я работаю с багами

Нашёл → воспроизвёл → описал шаги и ожидаемый результат → исправил → перепроверил на реальном
устройстве в Telegram. В каждом репорте указан коммит с исправлением, поэтому всё проверяется по
истории репозитория.

## Что я прокачал на этом проекте

- Ручное функциональное и UI-тестирование мобильного WebView (Telegram iOS/Android)
- Баг-репорты, тест-кейсы, чек-листы, регрессия после исправлений
- Проверка фактов и контента (гайды по игре)
- Проверка платежей (Telegram Stars) и сетевых сбоев (таймауты, недоступный сервер)
- Основы GitHub Actions (деплой) и работы с git-историей
- Работа в Chrome DevTools и Telegram WebApp API на базовом уровне

> Примечание о достоверности: даты в баг-репортах — это даты коммитов с исправлением,
> а не даты обнаружения. Раздел «Как нашёл» заполнен автором со слов.
