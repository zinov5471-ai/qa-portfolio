# Тест-план: Olden Era Course (Telegram Mini App)

## 1. Объект тестирования

Мини-приложение в Telegram: главная, темы и уроки, песочница (квизы), премиум-раздел
(гайды, калькуляторы, подписка за Stars), обратная связь, переключение языка RU/EN.

## 2. Окружение

- Telegram: iOS и Android (мобильный WebView), Telegram Desktop для быстрых проверок
- Chrome DevTools (эмуляция мобильного экрана, Network → Offline / Slow 3G)
- Бэкенд: Cloudflare Worker (обратная связь, проверка подписки, счётчики)

## 3. Типы проверок

1. Функциональные: навигация, квизы, обратная связь, подписка
2. UI/UX: скролл, кнопка «наверх», тактильный отклик, отображение экранов
3. Сеть: медленное соединение, недоступный Worker, офлайн
4. Контент: сверка фактов в гайдах с актуальной версией игры (патчи)
5. Регрессия: после каждого исправления проверяю соседние экраны

## 4. Критерии

- **Вход:** новая сборка на GitHub Pages
- **Выход:** критичные и высокие баги закрыты, регрессия по smoke-набору пройдена

## 5. Smoke-набор

TC-001, TC-003, TC-006, TC-009, TC-012, TC-015

## 6. Риски

- Поведение Telegram-клиентов различается по версиям (iOS/Android)
- Платёжные сценарии (Stars) тестируются ограниченно
