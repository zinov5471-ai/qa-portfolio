# Тест-кейсы: Olden Era Course (Telegram Mini App)

Окружение: Telegram (iOS/Android), Chrome DevTools. Все кейсы выполнялись вручную.

| ID | Название | Предусловие | Шаги | Ожидаемый результат | Статус |
|---|---|---|---|---|---|
| TC-001 | Открытие мини-приложения | Пользователь авторизован в Telegram | Открыть бота → нажать «Открыть приложение» | Приложение загружается, отображается главная с плитками тем | Passed |
| TC-002 | Переключение языка RU→EN | Открыто приложение | Нажать переключатель языка → выбрать EN | Весь интерфейс и контент переключаются на английский без перезагрузки | Passed |
| TC-003 | Открытие темы и урока | Главная открыта | Нажать на плитку темы → выбрать урок | Урок открывается, отображаются текст, изображение и квиз | Passed |
| TC-004 | Прохождение квиза (верный ответ) | Открыт урок с квизом | Выбрать правильный вариант | Ответ отмечен как верный, показывается объяснение | Passed |
| TC-005 | Прохождение квиза (неверный ответ) | Открыт урок с квизом | Выбрать неправильный вариант | Ответ отмечен как неверный, показывается правильный вариант | Passed |
| TC-006 | Кнопка «наверх» на длинной теме | Открыта длинная тема, страница прокручена вниз | Нажать кнопку «↑» | Страница плавно прокручивается в начало | Passed |
| TC-007 | Возврат на главную из урока | Открыт урок | Нажать «Назад» / домашнюю | Возврат на главную, прокрутка в верхнюю позицию | Passed |
| TC-008 | Экран «Тема пройдена» | Пройден последний урок темы | Завершить урок | Показывается финальный экран темы, нет пустого экрана | Passed |
| TC-009 | Тактильный отклик (haptic) | Устройство с поддержкой вибрации, Telegram | Нажать на интерактивный элемент | Кратковременный тактильный отклик | Passed |
| TC-010 | Премиум-раздел: доступ без подписки | Нет активной подписки | Открыть премиум-тему | Показывается экран с предложением подписки | Passed |
| TC-011 | Оплата Telegram Stars (успех) | Аккаунт с балансом Stars | Нажать «Оформить» → подтвердить оплату | Оплата проходит, подписка активируется, премиум-контент открывается | Passed |
| TC-012 | Оплата: блокировка Apple/Google | Встроенная покупка недоступна | Открыть премиум | Показывается блок «Нет звёзд?» с альтернативой | Passed |
| TC-013 | Форма обратной связи | Открыто приложение | Заполнить и отправить форму | Сообщение уходит в Cloudflare Worker, приходит подтверждение | Passed |
| TC-014 | Обратная связь: пустая форма | Открыта форма | Нажать «Отправить» без данных | Отправка блокируется, показывается валидация | Passed |
| TC-015 | Офлайн-режим | Приложение открыто, включён режим Offline | Попробовать открыть тему / отправить форму | Показывается понятное сообщение об ошибке, приложение не «зависает» | Passed |
| TC-016 | Медленное соединение (Slow 3G) | Открыто приложение | Включить Slow 3G → открыть урок | Контент загружается с индикацией, без пустого экрана | Passed |
| TC-017 | Недоступный Worker | Заблокирован запрос к Worker | Отправить форму обратной связи | Показывается ошибка отправки, данные не теряются молча | Passed |
| TC-018 | Прокрутка после «Урок пройден» | Длинный урок пройден до конца | Завершить урок | Страница прокручивается наверх, экран не остаётся пустым | Passed |
| TC-019 | Переход в премиум после завершения темы | Показан экран «Тема пройдена» | Открыть премиум-раздел | Экран «Тема пройдена» скрывается, премиум отображается поверх | Passed |
| TC-020 | Сверка контента с патчем игры | Открыта тема с данными о патче | Сверить цифры с официальным патчноутом | Данные соответствуют актуальной версии игры | Passed |
